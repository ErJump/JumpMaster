# Glossario D&D — IT ↔ EN

> I dati di gioco dell'SRD sono **in inglese**, l'interfaccia è **in italiano**.
> Questo file è la fonte di verità per le traduzioni ed è usato sia dagli agenti sia dalla feature
> "Glossario" dell'app (`src/features/glossary/`). Quando aggiungi un termine qui, aggiornalo anche
> nel dataset della feature.
