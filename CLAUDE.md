Le istruzioni operative per questo repo sono in **[AGENTS.md](./AGENTS.md)**. Leggilo per intero
prima di scrivere codice: è vincolante e `npm run guard` ne verifica le regole.

## Avvio rapido di ogni sessione

1. Leggi `docs/memory/active-context.md` → su cosa si stava lavorando
2. Leggi `docs/memory/progress.md` → cosa funziona e cosa manca
3. Se la richiesta riguarda una feature, apri la sua spec in `docs/specs/`
4. Alla fine del lavoro **aggiorna entrambi i file di memory nello stesso commit**
